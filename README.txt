TASK 03 - TIC-TAC-TOE WEB APPLICATION
========================================

Created for Nikshith Jampala.

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html.
4. Right-click -> Open with Live Server, or click Go Live.
5. Play the game.

Features:
- Player X and Player O
- Vs Computer mode
- Two Player mode
- Winning-condition detection
- Draw detection
- Scoreboard
- New Game button
- Winning cells highlighted
- Responsive layout
- Fixed navigation
- Smooth scrolling
- HTML + CSS + JavaScript

The computer opponent uses simple strategy:
1. Win if possible
2. Block the player
3. Take the center
4. Choose a corner
5. Choose any available cell
